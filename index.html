Welcome to Stat Tracker 👋

A tracker for analyzing your performance across drops. Built to compare hit rates, account groups, proxies, and bots over time.
This is a sample copy — there are 2 example drops loaded so you can see how things look filled out. Once you're ready to use it for real, scroll to the bottom and hit the Reset button to wipe everything clean.

Quick Start

  1. Go to the Config tab and set up your account groups (click ✕ on the example ones first if needed)
  2. Add your proxy presets — common names you use like HMA, MACINCLOUD, etc.
  3. Back on Drops, edit servers, bots, tasks, and account assignments directly in the tables — everything saves as you type
  4. Hit ✓ Done Editing to save your config
  5. You're ready — fill in checkouts as drops happen and hit Save Drop

How It Works

Drops Tab

The main page. Each "drop" represents one product release you ran. Enter checkouts per refract/shikari instance, add tags, write a recap, and stats / hit rates calculate automatically. Use + New Drop to start fresh, Save Drop to lock it in (auto-save also handles this in the background).

Config Tab

Where you set up everything that supports your drops:

  • Account Types — fully customizable categories (e.g. ME, ACO, Resi). Edit names and colors, add or delete types.
  • Account Groups — actual groups of accounts (e.g. "My Accts 1-3000"). Assign them to refracts on the Drops page. Use the ▲▼ arrows to reorder them.
  • Proxy Presets — save common proxy names so they autocomplete when filling proxy fields.
  • Server Presets — save common server names so they autocomplete when editing setup.
  • Defaults — set the default task count for new refract / shikari rows.

Analytics Tab

Auto-generated charts across all your saved drops. Use the Drop dropdown at the top to switch between "All drops" (aggregate view) and any specific drop you've saved. When viewing a single drop, the page re-scopes to just that drop's numbers.

What you'll see in All drops mode:

  • Summary cards — total checkouts, average per drop, best/worst drops, best hit rate
  • Drop Comparison table — every drop ranked 🥇🥈🥉 with their checkouts, hit rate, tags, and bot breakdowns
  • Account Group / Site Performance bar charts
  • Checkouts Timeline — toggle between Per Drop / Weekly / Monthly to spot longer-term trends

Plus 4 proxy charts (see below). Hit ↓ Export CSV any time to pull all drops into a spreadsheet.

📊 Per-Drop Analytics

On the Drop History grid, every card has a green 📊 button. Click it and you'll jump straight to the Analytics tab filtered to just that drop — useful when you want to dig into a specific drop without losing the aggregate view. To go back to the full picture, change the dropdown back to "All drops".

Proxy Performance

Four separate charts on the Analytics tab so same-name proxies running in different roles don't get mixed up:

  • Refract — Task Proxy — refract rows where only Task Proxy was set
  • Refract — Que Proxy — refract rows where Que Proxy was set. Each bar shows a small "w/" line listing the Task Proxy(s) it was paired with and how many times
  • Shikari — Proxy — Shikari Proxy field only (Fallback Proxy ignored)
  • All Proxies — Combined — every proxy ranked by total checkouts regardless of role. Hover any bar for the role breakdown

Each chart shows total checkouts and hit rate per proxy. Hover to see how many times the proxy was used across your drops.

Tags & Recap

Tag drops as successful, flop, or any custom tag. The recap field is for context — site issues, queue times, anything worth remembering when you look back later. Filter by tag in the Drop History.

Drop History & Compare

Below the current drop on the Drops tab is your full history. Search by name, filter by tag or site, sort by newest/oldest/best/hit rate. Each card has buttons to Load, jump to 📊 Analytics, Duplicate, or Delete.

Click ⇄ Compare to put two drops side-by-side. Winners are highlighted in green, losers in grey, ties in yellow. Includes per-instance breakdown so you can see exactly which servers/proxies performed differently between drops.

Duplicate opens a modal asking whether you want to copy just the setup (proxies, account groups, notes) or the full drop including checkouts. Useful for restocks where the config stays the same.

Templates

Save a fully configured drop as a reusable template. Useful for recurring sites where the setup stays similar — applying a template starts a new drop with your saved config and proxies pre-filled. Find this section at the bottom of the Drops tab.

Auto-calculated Ratios

The Ratio column on each refract/shikari row updates automatically based on how many instances share the same account group. Each unique ratio gets its own color so you can spot patterns at a glance (e.g. all 5:1 rows might be blue, all 3:1 pink).

Updates & Versioning

Good news: When a new version of the file drops, your saved data (drops, configs, account groups, etc.) carries over automatically when you open the new file in the same browser. New features just appear on top of your existing data.

The catch: If you rename the file or save it to a different location, the browser may treat it as a brand new file and not see your old data. To avoid this, always open the tracker from the same place (e.g. always double-click stat_tracker.html in your Downloads folder).

Check the Updates tab any time you download a new version to see what's new. The version badge next to the title (e.g. v1.4) tells you which version you're on.

Important: All data lives in your browser's localStorage. If you clear your browser cache or switch devices, you'll lose everything. Always export a backup before doing anything risky — including before opening a new version of the file for the first time.

Tips

  • Auto-save runs ~400ms after every keystroke — you'll see "Saving..." flash, then "Saved"
  • Use Hide Unused to focus only on refracts that hit checkouts
  • Click ▾ next to Refract or Shikari to collapse those sections
  • Account types are fully customizable in the Config tab — colors, names, everything
  • Click the title (or caret) on Proxy / Server Presets in Config to collapse them when not editing
  • Use Drop Templates if you run the same site repeatedly with similar setup
  • The 📊 button on history cards is the fastest way to dig into a single drop's stats
  • For Refract rows, fill in Que Proxy separately if you use a different proxy for the queue vs tasks — the analytics pair them automatically
  • Switch the Analytics timeline to Weekly or Monthly to spot longer-term trends
  • Export a JSON backup from the Config tab regularly — especially before clearing browser data or switching browsers

Reset to Fresh Template

This wipes all data — drops, history, account groups, types, proxies, templates, everything. Use this when you've explored the examples and want to start fresh with your own setup.

It will reload the page with an empty starter template.
